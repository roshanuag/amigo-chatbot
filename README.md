# Amigo Chatbot 🤖

A simple and interactive text-based chatbot built with Python. This repository marks my very first project in Python programming, focusing on foundational logic, control flow, and user interaction.

## Features
* **Interactive CLI:** Engages with users directly through the command line terminal.
* **Lightweight:** Runs entirely on standard Python libraries with no complex external dependencies.
* **Foundational Python:** Demonstrates core programming concepts like variables, loops, conditional statements, and user input handling.

## Prerequisites
To run this project, you will need Python installed on your local machine.
* [Python 3.x](https://www.python.org/downloads/)
